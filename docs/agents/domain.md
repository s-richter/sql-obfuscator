# Domain Docs

This is a single-context repo.

Before exploring, read:

- `CONTEXT.md` at the repo root, if present.
- Relevant ADRs under `docs/adr/`, if present.

If these files do not exist, proceed silently. Producer skills create them lazily when domain terms or architectural decisions are resolved.

Use the glossary vocabulary from `CONTEXT.md` when naming domain concepts. If a proposal contradicts an ADR, surface the conflict explicitly.
